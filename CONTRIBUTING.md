# Contribuir a Shard

Los issues son bienvenidos. Úsalos para reportar errores o proponer cambios.

Antes de enviar un pull request, abre un issue y espera a que el autor del proyecto acepte la propuesta. Incluye el enlace al issue en el PR.

Shard y sus contribuciones se distribuyen bajo la licencia GPLv3. Consulta [LICENSE](LICENSE).
